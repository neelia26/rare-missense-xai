# Protocol amendment 001: final primary feature count

Date: 14 November 2026  
Status: recorded before the first baseline result was accepted and before any validation or test outcome was accessed

The initial grouped-additive configuration recorded 48 primary predictors. Before the first governed baseline was accepted, the amino-acid block was corrected to exclude continuous polarity delta while retaining hydropathy delta and the separate polarity-class-change indicator. The primary condition therefore contains 47 predictors.

The population-frequency experiment remains a registered training-only sensitivity analysis. Maximum-population allele frequency is the selected numerical sensitivity feature. An availability-only diagnostic and a comparison restricted to the same frequency-observed variants are required to distinguish numerical frequency signal from database-coverage signal.

This amendment does not change the frozen cohort, gene-separated partitions or test policy. Validation and test outcomes were not accessed.
