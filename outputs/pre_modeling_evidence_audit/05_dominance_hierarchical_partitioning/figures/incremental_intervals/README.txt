Final incremental interval figures

Each bar is the observed change in pooled out-of-fold MCC when the named
feature is added last:

    full evidence block - the same block without that feature

Each black capped whisker is the paired 95% gene-bootstrap interval from
5,000 gene resamples. An interval entirely above zero is labelled positive.
An interval crossing zero is labelled uncertain.

The right-side dominance percentage is the feature's normalised Shapley share
across all subset contexts. It describes average contribution and is not the
same statistic as the added-last MCC change or its interval.
